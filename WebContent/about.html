SYSTEM DESIGN

Architectural Highlights

Application Layer

High-concurrency Java HTTP Servlets processing REST-style JSON endpoints via Google Gson. Decoupled controller-service-DAO design with clean exception propagation.

Persistence Tier

MySQL 8.0 relational database with JDBC 8.0 driver. Parametric queries prevent SQL injections, transactional updates safeguard stock during high-volume checkouts.

Modern UX Engine

Custom glassmorphic styling, async fetch pipelines, toast notifications, slide-over cart drawer, and client-side real-time filter indexing.

Technologies & Core Standards

Java JDK 8+ Java Servlets & JSP API MySQL Server 8.0 MySQL Connector/J 8.0 Apache Maven Embedded Tomcat (Webapp-Runner) ES6+ JavaScript Async/Await Glassmorphism & Vanilla CSS
